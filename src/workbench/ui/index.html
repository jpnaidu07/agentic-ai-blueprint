KEEP THE CHOICE EVIDENCE-BASED

There is no universal “best model”.

  1. Check the data boundary.Use cloud only when the selected data can leave this computer.
  2. Test compatibility.The connection probe verifies a structured JSON response and reports observed latency.
  3. Evaluate your task.Review capability quality, tests and failure cases. A small connection test is not a quality benchmark.
  4. Measure the tradeoff.Compare accuracy, abstention, latency and actual usage before choosing for production.

For Intel integrated graphics, system RAM is shared. Ollama's Vulkan path is experimental; start small and verify the runtime actually uses your GPU.

Prerequisites & explicit actions

Ollama runtime

Install through Winget on Windows or Homebrew on macOS when available. Other systems get official manual steps. No downloaded shell script is executed automatically.

Official download ↗

Docker

Required only to test or launch generated code safely. Install Docker, enable the supported virtualization backend, and start the daemon.

docker infoInstall Docker ↗

Isolated Python runner

Build the pinned execution image once. Tests run without network, credentials or host-repository access, with time, memory and process limits.

Image downloads and package installation use network during image build only.
